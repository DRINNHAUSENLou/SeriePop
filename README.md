<h1 align="center">SeriePop</h1>

<p>
SeriePop est un site web accessible à tous les utilisateurs, inspiré d’une plateforme de streaming de séries.
</p>

<p>
Ce projet a été réalisé dans le cadre d’un exercice visant à concevoir une interface respectant les bonnes pratiques d’accessibilité numérique, afin de garantir une utilisation optimale pour tous, y compris les personnes utilisant des technologies d’assistance comme les lecteurs d’écran.
</p>

<p>
Le site permet de découvrir différentes séries à travers une interface simple et structurée.<br>
Les utilisateurs peuvent consulter les informations principales telles que le titre, le synopsis ou encore les catégories.
</p>
