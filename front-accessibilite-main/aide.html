Page d’Aide

Cette page vous guide dans l’utilisation du site en tenant compte des besoins d’accessibilité : agrandissement du texte, navigation au clavier, activation d’un lecteur d’écran, accès aux transcriptions et contacts en cas de difficulté.

Agrandir le texte

Pour agrandir ou réduire la taille du texte :

  • Windows : Ctrl + + ou -
  • Mac : ⌘ Command + + ou -
  • Menu navigateur → "Zoom"

Utiliser les raccourcis clavier

  • Tab → passer d’un élément à l’autre
  • Shift + Tab → revenir en arrière
  • Entrée → activer un lien ou bouton
  • Espace → cocher/décocher une case

Activer un lecteur d’écran

Selon votre appareil :

  • Windows : NVDA (gratuit), JAWS (payant), Narrator (intégré)
  • Mac / iPhone : VoiceOver (intégré)
  • Android : TalkBack (intégré)

Transcriptions et sous-titres

Toutes nos vidéos disposent d’une transcription textuelle ainsi que de sous-titres. Vous pouvez les retrouver directement sous chaque vidéo ou sur la page dédiée : Accéder aux transcriptions.
